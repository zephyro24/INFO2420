Website Color Scheme

The website uses an adjacent color scheme based on the main color #F6A4AC. The colors were selected to create a soft, professional, and readable design.

Color Sample Hexadecimal Value Usage
  #F6A4AC Main accent color
  #FFE1E5 Background color
  #E98B98 Secondary accent color
  #D66F82 Heading color
  #B85C73 Link color
  #333333 Body text color
