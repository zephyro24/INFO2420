Website Color Scheme

The website uses a soft blue and green color scheme designed to create a clean, professional, and accessible appearance. The colors were selected to provide good readability while maintaining WCAG-compliant contrast.

Color Sample Hexadecimal Value Usage
  #EAF4F4 Background color
  #333333 Body text color
  #3D5674 Main heading color (H1, H2)
  #4E6A89 Subheading color (H3)
  #476A44 Link color
  #2F4A2D Hover and focus link color
